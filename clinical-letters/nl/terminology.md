# Terminology: ontslagbericht (Netherlands)

All persons, institutions and identifiers in this bundle are invented.
(konventie) = common Dutch practice, not a HASP rule; (UNVERIFIED) = no
primary source read for this bundle.

## Code systems (convention, not a HASP requirement)

HASP requires no coding; it only asks that a code, when shown, carries its
description, and maps rubrieken to BgZ/ZIB building blocks "nog niet
aangegeven" for most rubrieken. Common Dutch practice:
- Diagnoses in hospitals: ICD-10 via the DHD Diagnosethesaurus; DBC/DOT
  zorgproduct codes for billing (konventie, UNVERIFIED).
- Diagnoses in GP systems: ICPC-1 episode codes (konventie).
- Drugs: G-Standaard (Z-Index) article/product codes, ATC classification
  (konventie, UNVERIFIED).
- Lab: NHG-tabel 45 / LOINC (konventie, UNVERIFIED).
Write diagnoses in words; add a code only if the record has one, with its text.

## Units, numbers, dates

- Units from HASP examples: mmol/l, µmol/l (also written umol/l), mg/l,
  g/l, U/l, pmol/l, mU/l, 10^9/l, mmHg, ml/min/1,73 m2, kg, cm, %.
- Decimal comma in Dutch text: 7,9 mmol/l; 73,8 kg. Thousands without separator.
- Dates: HASP fixes no notation and its examples mix 2016-09-02, 12-12-2014
  and 26.07.2016. Use DD-MM-JJJJ throughout (konventie); time HH:MM, 24 h.
- Blood pressure: 125/80 mmHg; pulse: 67/min; temperature: 38,9 °C; SpO2: 91%.

## Abbreviations to avoid in rubriek text

HASP: abbreviations "verdient daarom zeer terughoudend gebruik". Write out:
SEH (spoedeisende hulp), OK (operatie), IC (intensive care), DM2 (diabetes
mellitus type 2), HF (hartfalen), AF (atriumfibrilleren), HT (hypertensie),
CVA (beroerte), MI (myocardinfarct), COPD may stay (standard name), LO
(lichamelijk onderzoek), RR (bloeddruk), VAG (vesiculair ademgeruis), g.b.
(geen bijzonderheden), i.v.m. (in verband met), mn (met name), ia (in het
algemeen), zn (zo nodig), pte/pt (patiënt), dd in prose (per dag), AB
(antibiotica), NF (nierfunctie), OAC (orale anticoagulantia). Dose shorthand
"1 dd 1" is tolerated inside the Medicatie list (HASP examples use it), not
in Kern prose. A written-out term may be followed once by "(abbr.)".
