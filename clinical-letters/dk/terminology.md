## Follow-up marking (§3, DR)

| Category | Danish wording to write as first line of the Anbefaling section |
|---|---|
| Red: GP follow-up within 1–2 working days, hospital phones GP; only after admission, exceptional | Markering: Rød – opfølgning hos egen læge inden for 1-2 hverdage; afdelingen har kontaktet egen læge telefonisk DD.MM.YYYY |
| Yellow: vulnerable patient, active GP follow-up within 14 days; only after admission | Markering: Gul – opfølgning hos egen læge inden for 14 dage (reason for vulnerability) |
| Green: recommendations given, patient contacts GP | Markering: Grøn – anbefalinger til egen læge, patienten henvender sig selv |
| White: no recommendation, information only | Markering: Hvid – ingen anbefaling om opfølgning |

Writing the colour in words is this experiment's convention; DR says the new
MedCom standard derives the colour in the GP system from the author's answers.

## Code systems

| Use | System | Notes |
|---|---|---|
| Diagnoses | SKS (Sundhedsvæsenets Klassifikations System), Danish ICD-10 adaptation; codes start with D, e.g. DI500 Kongestiv hjerteinsufficiens, DI489 Atrieflimren, DE119 Type 2-diabetes, DJ441 KOL med akut eksacerbation | MedCom: "officielle SKS-diagnoser"; owner Sundhedsdatastyrelsen (UNVERIFIED) |
| Procedures | SKS operation and procedure codes (K-chapter for operations, e.g. KJJB40), with date | MedCom |
| Drugs | Generic substance name; ATC code optional, e.g. furosemid C03CA01, spironolakton C03DA01, apixaban B01AF02 | konvention; ATC not required by any source read |
| Medication truth | FMK | §2.8 |
| Patient identifier | CPR-nummer DDMMYY-XXXX | konvention |

## Date and time

DD.MM.YYYY (e.g. 19.10.2026); time "kl. 08.00"; intervals "26.10.2026–28.10.2026";
working days "hverdage" (MedCom example; konvention).

## Specialty abbreviations to avoid (§2) and the written-out form

| Avoid | Write |
|---|---|
| HFrEF / HFpEF | hjertesvigt med nedsat / bevaret pumpefunktion (heart failure with reduced / preserved ejection fraction) |
| EF, LVEF | ejektionsfraktion (venstre ventrikels pumpefunktion) |
| TTE / TEE | transthorakal / transøsofageal ekkokardiografi (ultralyd af hjertet) |
| AFLI / AF | atrieflimren |
| NSTEMI / STEMI / AKS | blodprop i hjertet uden / med ST-elevation; akut koronart syndrom |
| KAG, PCI | hjertekateterisation (kranspulsåreundersøgelse), ballonudvidelse |
| LAE / DVT | lungeemboli / dyb venetrombose |
| NOAK / DOAK | direkte oral antikoagulans (blodfortyndende tablet) |
| AK | antikoagulationsbehandling (blodfortyndende) |
| SGLT2-i, ACE-i, ARB, MRA | write the drug class and the drug name |
| GCS, NIHSS, NYHA, CHA2DS2-VASc | write the scale name once in full, then the score |
| p.n. | efter behov (as needed) |
| i.v. / p.o. / s.c. | i blodåren / gennem munden / under huden |
| UL, CT, MR, rtg. | ultralyd, CT-skanning, MR-skanning, røntgen |
| pt., amb., afd., sepon. | patienten, ambulatoriet, afdelingen, seponeret |
| ERCP, EGD, KOL (acceptable), CRP (acceptable) | write out the first three; KOL and CRP are general knowledge for a GP |

Rule of thumb: an abbreviation a Danish GP sees daily (BT, CRP, KOL, EKG, CT,
FMK) is acceptable; anything specific to a hospital specialty is written out at
first mention.
