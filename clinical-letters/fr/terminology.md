## Medication status vocabulary

Use exactly one per drug: `instauré` (started), `modifié` (changed),
`poursuivi` (continued), `arrêté` (stopped). `modifié` and `arrêté` always
carry a motif.

## Code systems

| What | System | Source |
|---|---|---|
| Diagnoses / problems | CIM-10 | ANS CI-SIS LDL-SES V2020.01 codes problems in CIM-10 |
| Drugs | DCI (dénomination commune internationale), nom commercial optional in brackets | HAS QLS criterion 11 |
| Procedures | French wording; CCAM code if known | CCAM use not verified in the sources read (UNVERIFIED) |
| Physician identifier | RPPS | convention; never invent one |
| Patient identifier | INS (identité nationale de santé) | convention; never invent one |

## Units and numbers

French laboratories report (conventions, not fixed by the sources read,
UNVERIFIED):

| Analyte | French unit | Common US unit to convert from |
|---|---|---|
| Créatinine | µmol/L | mg/dL (x 88.4) |
| DFG estimé | mL/min/1,73 m² | same |
| Glycémie | mmol/L, also g/L | mg/dL (x 0.0555 for mmol/L) |
| HbA1c | % (and mmol/mol) | % |
| Hémoglobine | g/dL, also g/L | g/dL |
| Cholestérol | g/L, also mmol/L | mg/dL |
| Potassium, sodium | mmol/L | mEq/L (1:1) |
| Protéine C-réactive | mg/L | mg/L |

Decimal separator: comma in French text (`1,73 m²`, `0,5 mg`). Dates
`JJ/MM/AAAA`. Times `14 h 30`. Convert any `MM/DD/YYYY` date from the source
record.

## Abbreviations

Expand at first use, then the abbreviation may follow in brackets. Common
French clinical abbreviations and their expansions:

| Abbreviation | Expansion |
|---|---|
| ATCD | antécédents |
| AVK | antivitamine K |
| AOD | anticoagulant oral direct |
| ETT | échographie transthoracique |
| FEVG | fraction d'éjection ventriculaire gauche |
| HTA | hypertension artérielle |
| IDM | infarctus du myocarde |
| IRC | insuffisance rénale chronique |
| MRC | maladie rénale chronique |
| NFS | numération formule sanguine |
| RDV | rendez-vous |
| SAU | service d'accueil des urgences |
| TDM | tomodensitométrie |
| ALD | affection de longue durée |
| BMR / BHRe | bactérie multirésistante / hautement résistante émergente |
| DMP | dossier médical partagé |
| MSSanté | messagerie sécurisée de santé |

Do not use English abbreviations (CKD, HFrEF, CRP is acceptable as CRP) or
abbreviations from the source record without expanding them.
